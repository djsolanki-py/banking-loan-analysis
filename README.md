## 📊 Project Overview

This project focuses on analysing banking and loan-related data using Microsoft Power BI.

The dashboard provides insights into loan distribution, loan status, customer activity, branch performance, interest earned and loan disbursement trends.

The objective is to transform banking data into meaningful visual reports that help understand loan portfolio performance and customer activity.

## 🎯 Business Objectives

- Analyse the total loan amount issued by the bank.
- Compare active and closed loans.
- Identify the highest loan amounts.
- Analyse loan distribution by loan type and status.
- Evaluate branch-wise loan amounts and revenue.
- Understand customer loan distribution and demographics.
- Monitor monthly and yearly loan trends.
